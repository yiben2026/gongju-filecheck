========================================
  文件核查工具 · 部署说明
========================================

【文件清单】
  文件核查.html    ← 前端页面（放进你的网站）
  server.js        ← 后端服务（核查引擎）
  package.json     ← 依赖配置
  启动服务.bat      ← 一键启动脚本


【安装步骤】

1. 安装 Node.js（只需一次）
   - 下载地址：https://nodejs.org
   - 选 LTS 版本，一路下一步安装
   - 安装后打开 cmd 输入 node -v 确认可用

2. 放置文件
   - 把整个「文件核查部署包」文件夹复制到你的网站目录下
   - 比如放在 D:\我的网站\文件核查\

3. 首次启动
   - 双击「启动服务.bat」
   - 首次运行会自动安装依赖包（express, axios, cheerio）
   - 等待出现「文件核查服务已启动」即表示成功

4. 日常使用
   - 每次用之前，双击「启动服务.bat」
   - 浏览器打开 http://localhost:3456/文件核查.html
   - 上传 PDF → 点「开始核查」→ 等待结果


【嵌入你的大网站】

方法A：直接链接（推荐）
  在你的首页加一个入口卡片，链接指向：
  http://localhost:3456/文件核查.html

方法B：iframe 嵌入
  在你的页面中插入：
  <iframe src="http://localhost:3456/文件核查.html"
          style="width:100%;min-height:800px;border:none;">
  </iframe>

注意：前端页面顶部已加好返回导航栏，
把 href="index.html" 改成你的首页地址即可。


【注意事项】

· 服务运行期间不要关闭 cmd 黑窗口
· 每次重启电脑后需要重新双击 bat 启动
· 端口 3456，如冲突可在 server.js 第11行修改
· 需要联网才能搜索核查
· PDF 文本提取在前端完成，核查搜索在后端完成

【技术栈】
  前端：HTML + pdf.js（CDN加载）
  后端：Node.js + Express + Axios + Cheerio
  搜索引擎：百度（主） + Bing（备）
